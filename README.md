# PharmaSphere — Этап 1: Архитектурный фундамент и русскоязычный интерфейс

Современная образовательная платформа и справочник по клинической фармакологии для студентов медицинских вузов.

## Реализованный функционал (Этап 1)

- **Полная русская локализация**: Весь пользовательский интерфейс, навигация, карточки препаратов, фармакологические группы, учебные модули, клинические задачи с пояснениями, уведомления и дисклеймеры переведены на естественный медицинский русский язык с сохранением международных названий (МНН) и стандартных аббревиатур.
- **Оболочка приложения и дизайн-система**: Постоянная темно-синяя (`#0B1528`) боковая панель на десктопе, компактный режим на планшете, адаптивное выдвижное меню на мобильных экранах, переключение светлой и темной темы.
- **Главная панель (Дашборд)**:
  - Персональное приветствие с нейтральным вариантом по умолчанию («С возвращением!»), глобальный поиск и быстрый переход в справочник.
  - **Статистика обучения**: Демонстрационные показатели (`142` вопроса, `88%` правильных ответов, `14` завершенных тем, серия `6 дн.`) с явной меткой `Демо-статистика`.
  - **Продолжить обучение**: 3 учебных модуля по системам органов с индикаторами прогресса.
  - **Вопрос дня по фармакологии**: Интерактивная клиническая задача с проверкой ответа, объяснением механизма действия, защитой от повторного начисления баллов, переключением между 3 задачами и сбросом состояния.
  - **Популярные препараты**: Карточки эталонных препаратов (`Метопролол`, `Лизиноприл`, `Атропин`, `Фуросемид`) с добавлением в избранное и переходом к полному профилю (`/drugs/[id]`).
  - **Недавно изученные**: Автоматическая запись действий текущей сессии с четким разграничением от начальной демо-истории.
  - **Быстрые действия**: Прямые ссылки на `/drugs`, `/groups`, `/learning` и `/favorites`.

## Команды

```bash
npm run dev        # Запуск сервера разработки
npm run typecheck  # Строгая проверка типов TypeScript (tsc --noEmit)
npm run lint       # Проверка ESLint без предупреждений
npm run build      # Продакшен-сборка Next.js
npm run start      # Запуск продакшен-сервера
```
